# 开源项目参考目录

以下项目来自公开 GitHub 开源仓库。这里保存的是项目索引，不把第三方项目源码未经必要审查直接复制进本仓库。

## 游戏 / 游戏网站

### 1. zeli-web-games
150 个自包含 HTML5 / React 小游戏，涵盖 Snake、2048、Minesweeper、Sokoban、Asteroids、Bomberman 等。
- Repository: https://github.com/hajunho/zeli-web-games
- License: Apache-2.0
- 用途：小游戏合集、游戏逻辑参考、移动端小游戏架构。

### 2. IceStack
React + TypeScript + Canvas 拼图游戏，采用游戏逻辑与 UI 分离的结构。
- Repository: https://github.com/Yash-P29/IceStacck
- License: MIT
- 用途：Canvas 游戏、游戏状态管理、组件化游戏架构。

### 3. Mini Game Hub
React + Vite 的多小游戏平台，包含井字棋、贪吃蛇、数独、石头剪刀布、打字速度测试等。
- Repository: https://github.com/hamza5849/mini-game-hub
- 用途：小游戏网站导航、多个游戏集成。

### 4. React + Three.js Game Template
React + TypeScript + Vite + Three.js 的浏览器游戏模板，并包含音频、测试和安全检查等工程化配置。
- Repository: https://github.com/Hack23/game
- License: MIT
- 用途：3D 游戏、Three.js、React Three Fiber、游戏工程模板。

### 5. The Backrooms Online
React + Three.js + TypeScript 的浏览器 3D 探索游戏，包含程序化地图、实体 AI、WebSocket 多人同步等。
- Repository: https://github.com/SimonSaysGiveMeSmile/backroom
- License: MIT
- 用途：3D 浏览器游戏、多人同步、程序化地图、AI。

### 6. Bubble Shooter
React + TypeScript + Vite 的泡泡龙游戏，包含 Canvas、触屏、粒子效果和关卡。
- Repository: https://github.com/vivek-belwal/BubbleShooter
- License: MIT
- 用途：Canvas 游戏、触摸控制、粒子效果、关卡系统。

### 7. React Minesweeper
React 实现的经典扫雷项目，适合参考游戏状态、测试和部署到 GitHub Pages 的方式。
- Repository: https://github.com/jpo/react-minesweeper
- License: 项目页面未在摘要中明确展示许可证；复制前必须检查仓库 LICENSE。
- 用途：扫雷 UI、测试、静态部署。

### 8. Shadcn Dashboard
React + Vite + TypeScript + shadcn/ui 的开源后台模板，包含 Dashboard、认证页、表格、表单、用户资料、深色模式等。
- Repository: https://github.com/shadcndashboard/shadcndashboard
- License: MIT（项目 README 同时要求保留署名链接）
- 用途：管理后台、用户系统、数据表格、仪表盘。

### 9. React-admin
基于 React/TypeScript 的后台应用框架，提供认证、路由、表单、数据表格、搜索过滤、权限、通知等模块。
- Repository: https://github.com/marmelab/react-admin
- License: MIT
- 用途：管理后台、CRUD、REST/GraphQL API 对接。

### 10. Vital Admin Template
React + Vite + TypeScript 的后台模板，包含用户、商品、订单、项目、发票、分析、通知、认证和设置等完整模块。
- Repository: https://github.com/Miftah-Fentaw/React-admin-template
- License: MIT
- 用途：SaaS 后台、CRM、数据面板、电商后台、内部工具。
