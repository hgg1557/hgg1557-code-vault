# hgg1557 代码库

这是我的中央代码资产库（Code Vault）。

## 用途

这个仓库不是某一个单独项目，而是用于长期保存、整理和复用：

- 完整项目源码
- React / Vue / Vite / Next.js 等前端模板
- Node.js / Python 等后端代码
- UI 组件
- 登录、授权、管理后台等通用模块
- API、数据库和服务层代码
- 工具函数和代码片段
- 可复用项目模板
- 项目文档与技术方案

## 目录

- `projects/` — 完整项目
- `templates/` — 项目模板
- `components/` — 可复用组件
- `backend/` — 后端代码
- `frontend/` — 前端代码
- `snippets/` — 代码片段
- `shared/` — 跨项目通用代码
- `docs/` — 文档与索引

## 使用原则

1. 优先复用已有代码，再编写新代码。
2. 新项目的完整源码放入 `projects/`。
3. 具有通用价值的代码提取到对应的模板、组件或 shared 目录。
4. 不把密钥、Token、密码、私有环境变量等敏感信息提交到仓库。
5. 第三方开源代码必须遵守其许可证要求，并保留必要的版权与许可证信息。

## 目标

让这个仓库成为长期可检索、可复用、可持续扩充的个人代码资产库。
