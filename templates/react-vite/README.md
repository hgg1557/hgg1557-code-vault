# React + Vite Template

Baseline for small web apps and games.

Suggested stack:
- React
- TypeScript
- Vite
- optional Tailwind/shadcn
- shared utilities from this vault

Project conventions:
- keep game/business logic separate from UI
- keep API calls in service modules
- never commit secrets
- add tests for reusable pure logic
- deploy static frontends to Vercel when appropriate
